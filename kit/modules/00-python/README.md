# 00-python

Installs `uv` and CPython 3.12 under `$HOME` for the other modules. Offline, no sudo.
Needs `kit/offline/uv` and `kit/offline/python`.

```sh
cd ~/work/kit/modules/00-python && bash install.sh
bash uninstall.sh
```

Open a new terminal: `uv` is in `~/.local/bin`.

Module API and tests: `~/work/kit/docs/python.md`.
