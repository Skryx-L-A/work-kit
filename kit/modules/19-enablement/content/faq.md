# FAQ for facilitators and champions

Short answers to the questions that come up in almost every session. Replace every
`TODO(ask IT)` with the company's answer; until then say "not decided yet, the strict rule
applies".

**Which AI tools may I use?**
Only the approved ones: `TODO(ask IT)`. Personal accounts, free tiers and browser extensions
are not approved for work data.

**Can I use AI with customer data?**
Only in a tool approved for CUSTOMER data, and only if the customer's contract allows it.
`TODO(ask IT)`: which tool, if any. When unsure: no, ask first.

**Does the AI learn from what I type?**
Depends on the tool and the contract. Some consumer tools use inputs for training; business
contracts usually exclude it. Do not rely on memory: check the approved tool list.

**Is it cheating to use AI for my work?**
No, if the task suits AI, the data rules are kept, and you check the result. You remain
responsible for what you hand in. Say that you used AI when it matters to the reader (for
example in customer deliverables, if the contract requires it).

**Will AI replace my job?**
`TODO(ask IT)`: official statement. What is true in any case: the company's line is AI for
well-defined tasks with human review, so the review and the judgement stay with people.

**The answer was wrong. Is the tool broken?**
No. Generative AI produces plausible text, not verified facts. Give it the source text,
ask it to quote the passages it used, and check the claims.

**Can I let AI write to customers directly, without me?**
No. Every output that reaches a customer is reviewed by a person first.

**May I install a plugin, extension or a local model?**
Not without IT. Extensions often read everything on the page, including customer systems.

**Does AI output have copyright problems?**
It can reproduce existing text or code. Do not use long generated passages or code in
customer deliverables without review; developers follow the license checks in code review.
