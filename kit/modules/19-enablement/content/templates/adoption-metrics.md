# Adoption metrics

Collect every 4 to 6 weeks per team, by the champion. Numbers for teams, never for
individuals. Write where each number comes from; an estimate is marked as one.

Team: __________  Period: __________  Collected by: __________

| Metric | How to measure | Value | Source |
|---|---|---|---|
| People trained (baseline) | literacy record | | |
| People who completed a role track | literacy record | | |
| Active users | people who used an approved tool at least once a week (tool admin report or short survey) | | |
| Confidence | feedback form average, "I can check an AI result" | | |
| Tasks with AI support | count of recurring task types the team now does with AI | | |
| Time saved per week | per task type: (time before − time with AI − review time) × frequency; survey or timed sample | | |
| Rework caused by AI | cases where an AI error had to be fixed after it left the team | | |
| Incidents | data or output incidents reported | | |
| Shared prompts | prompts added to the team or company library | | |
| Use-case ideas submitted | intake forms or ideas passed on | | |

## Notes

- Count review time. Time saved without review time overstates the benefit.
- Rework and incidents are not failures of the team; report them so rules and material improve.
- If a number is unknown, write "unknown", not a guess.
