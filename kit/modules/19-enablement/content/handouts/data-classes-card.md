# What may go into which AI tool

Classify before you paste. A mix of data takes the strictest class. When unsure: ask first.

| Class | Examples |
|---|---|
| PUBLIC | Our website, published documentation, open-source code |
| INTERNAL | Internal process descriptions, wiki pages, meeting notes without customer content |
| CONFIDENTIAL | Contracts, prices, financials, HR and personal data of staff, passwords, security findings |
| CUSTOMER | Anything from or about a customer: code, logs, tickets, documents, names, systems |
