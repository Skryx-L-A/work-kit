# Improve a text

Use for: Making your own draft clearer, shorter or better suited to a reader.

Do not use for: Texts that must stay legally exact (contracts, policies): use a lawyer-reviewed template.

## Prompt

```text
Improve the following text for {{audience}}. Keep the meaning and every fact, name, date and
number unchanged. Make it clearer and shorter, in a {{tone}} tone. Below the text, list the
changes you made.

Text:
{{text}}
```

## Review before use

- Every fact, number and name is unchanged.
- Nothing was added that was not in the original.
- Tone fits the reader.
