# Explain a topic simply

Use for: Getting a first understanding of a concept, term or technology.

Do not use for: Facts you will rely on without checking (laws, prices, current versions).

## Prompt

```text
Explain {{topic}} to someone who {{background}}. Use one everyday example. Then say which
parts of your explanation are simplified, and where I should check an authoritative source.
```

## Review before use

- Key claims checked against an authoritative source before reuse.
