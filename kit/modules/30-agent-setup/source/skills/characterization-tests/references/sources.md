# Sources

- Michael Feathers, *Working Effectively with Legacy Code*, 2004, chapter 13 "I Need to Make a
  Change, but I Don't Know What Tests to Write" (origin of the term characterization test) and
  chapter 25 on dependency-breaking techniques for creating seams.
- Michael Feathers, "Characterization Testing", https://michaelfeathers.silvrback.com/characterization-testing
- Wikipedia, "Characterization test", https://en.wikipedia.org/wiki/Characterization_test
- Llewellyn Falco et al., Approval Tests, https://approvaltests.com/ (libraries for Java, .NET,
  Python, C++, JavaScript and others; approved/received file workflow).
- Emily Bache, "Gilded Rose Refactoring Kata", https://github.com/emilybache/GildedRose-Refactoring-Kata
  (practice exercise for golden-master tests before refactoring).
- Mutation testing tools as a check that tests detect changes: PIT (Java) https://pitest.org/ ,
  Stryker (JS/.NET/Scala) https://stryker-mutator.io/ , mutmut (Python) https://github.com/boxed/mutmut
