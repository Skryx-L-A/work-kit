# Sources

- OWASP Top 10:2025, https://owasp.org/Top10/2025/0x00_2025-Introduction/ (final release
  published in early 2026; checked 2026-09-24).
- OWASP Application Security Verification Standard (ASVS) 5.0.0, released May 2025,
  https://github.com/OWASP/ASVS
- OWASP Cheat Sheet Series, https://cheatsheetseries.owasp.org/
- OWASP Threat Modeling Cheat Sheet (STRIDE),
  https://cheatsheetseries.owasp.org/cheatsheets/Threat_Modeling_Cheat_Sheet.html
- MITRE CWE, https://cwe.mitre.org/ (reference IDs for findings)
- Gitleaks, https://github.com/gitleaks/gitleaks (secret scanning; the kit ships it via the
  data-guard module).
- OWASP Dependency-Check, https://owasp.org/www-project-dependency-check/ ; pip-audit,
  https://github.com/pypa/pip-audit
