# Sources

- ISO/IEC/IEEE 29119-1:2022, Software testing, general concepts (verification versus
  validation, test basis, test evidence).
- Google Testing Blog, "Flaky Tests at Google and How We Mitigate Them" (2016),
  https://testing.googleblog.com/2016/05/flaky-tests-at-google-and-how-we.html
- Martin Fowler, "Continuous Integration" (build and test every commit on the mainline),
  https://martinfowler.com/articles/continuousIntegration.html
- The risk-based choice of checking effort follows common practice in risk-based testing,
  for example ISTQB Foundation Level syllabus v4.0, chapter 5.2, https://www.istqb.org/
