# Sources

- David J. Agans, *Debugging: The 9 Indispensable Rules for Discovering Even the Most Elusive
  Software and Hardware Problems*, AMACOM, 2002 (make it fail, quit thinking and look, change
  one thing at a time, keep an audit trail). https://debuggingrules.com/
- Andreas Zeller, *Why Programs Fail*, 2nd ed., Morgan Kaufmann, 2009, and *The Debugging Book*,
  https://www.debuggingbook.org/ (scientific debugging, delta debugging).
- Git documentation, `git bisect`, https://git-scm.com/docs/git-bisect
- Karl Popper's falsifiability as the basis of "write the hypothesis so a test can refute it"
  (general scientific method, as applied in Zeller's work above).
