# Signs of generated text and what to write instead

Check a text against this list before it goes to other people. One occurrence is not a
problem; a pattern is.

| Pattern | Example | Instead |
|---|---|---|
| Antithesis framing | "This is not just a tool, it is a platform." | State what it is: "The tool imports and validates CSV files." |
| Triplets everywhere | "fast, secure, and scalable" | Name the one property that matters, with a number. |
| Parallel verb chains | "It parses, validates, transforms and stores the data." | Split into sentences in the order that matters. |
| Essay openers | "In today's fast-paced world...", "Let's dive in." | Start with the fact or the ask. |
| Signposting | "It is worth noting that...", "Importantly," | Delete; say the thing. |
| Hedging stacks | "could potentially help to possibly reduce" | "reduces X by Y (measured on Z)" or "not measured". |
| Empty intensifiers | "robust", "seamless", "powerful", "cutting-edge" | Describe the behaviour or drop the word. |
| Summary closers | "In conclusion...", "Overall, this demonstrates..." | End with the next step or the open question. |
| Uniform rhythm | every sentence 18 to 22 words | Mix short and long sentences. |
| Dash chains | three em dashes in a paragraph | Use periods, commas or parentheses. |
| Over-formatting | bold phrases in every line, headings for two sentences | Bold only for structure; prose for reasoning. |
| Flattery and apology | "Great question!", "I apologize for the confusion" | Omit in work text. |
| Invented specifics | "improves productivity by 40 %" without a source | Only numbers you measured or can cite. |

German texts show the same patterns ("nicht nur X, sondern auch Y", "Es ist wichtig zu
beachten", "Zusammenfassend lässt sich sagen"). The same fixes apply.
