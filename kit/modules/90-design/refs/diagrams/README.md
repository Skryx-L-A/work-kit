# diagrams

References for architecture diagrams, flow charts and charts.

Put here:
- example diagrams in the house style (PNG, SVG, PDF)
- the icon set or shape library the company uses (with its license)
- style notes: colours per component type, line styles, how to label systems
- chart examples that show the preferred look for data (also used by the dataviz skill)

No real hostnames, IP addresses or customer system names in examples.
