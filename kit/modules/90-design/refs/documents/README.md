# documents

References for reports, concepts, proposals and letters.

Put here:
- the Word template (`.docx`; save a `.dotx` as `.docx`). With exactly one `.docx` here,
  `kit-design doc -o out.docx` uses it as the style reference
- letterhead and example documents in the house style (PDF)
- rules for document metadata (version, classification label, file names) if they exist

No documents with customer or personal data.
