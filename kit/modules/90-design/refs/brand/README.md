# brand

Company identity that every deck, document, page and chart should follow.

Put here:
- logo files (SVG and PNG, light and dark versions)
- the brand or corporate design guide (PDF)
- colour codes and font names, ideally as `theme.json` (read by `kit-design`):

```json
{
  "colors": { "text": "#1d232b", "background": "#ffffff", "accent": "#0f5f8c",
              "muted": "#5c6670", "surface": "#eef2f5" },
  "fonts": { "heading": "Arial", "body": "Arial" },
  "logo": "logo.png"
}
```

Only material you are allowed to keep on this laptop. No customer material.
