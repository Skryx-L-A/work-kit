# Web prototype

Open `index.html` in a browser (works from `file://`), or `python3 -m http.server` in this folder.

- `tokens.css`: colours and fonts (from `design-refs/brand/theme.json` when present)
- `styles.css`: layout and components; `app.js`: behaviour; `data.js`: synthetic data
- `?state=loading|empty|error` shows the other states

Replace the sample screen with your own flow. Keep data synthetic.
