# Work kit

1. Read `02-laptop-setup.md` and ask your company's IT which modules are approved.
2. Get this repository in `~/work-kit`:
   `git clone https://github.com/Skryx-L-A/work-kit ~/work-kit`.
   Without Git, use GitHub's **Download ZIP** and unpack it to `~/work-kit`.
3. Run `bash ~/work-kit/setup/fetch-offline.sh` (about 15 GB; resumable; SHA-256 checked).
4. Run `bash ~/work-kit/setup/install-kit.sh` and choose modules in the menu.

`03-for-IT.md` lists changes, network use and removal. `04-daily.md` covers daily use. Printable versions: `00-README.pdf` and `03-for-IT.pdf`.
